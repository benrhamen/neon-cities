# Neon City Adventures

Four illustrated educational adventures using Neon Dragon rules.

- Rome: landmarks, food and twelve Western zodiac friends.
- Paris: fairy tales and La Fontaine friends.
- London: British folklore friends.
- New York: twelve original city Sparks.

Each city has 143 story sections, 16 items and twelve friends. Stories, sources and cultural caveats are included in the game. Scores stay in this browser; unfinished runs reset when the page reloads. The arcade hub owns the shared character; this game only reads its local device profile.

No ads, purchases, tracking, or runtime network API calls. Story-source links open only when selected.

## Build

Run `npm install`, then `npm run build`. Static files in the repository root are ready for GitHub Pages.
